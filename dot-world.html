Dot World — a dot's cycle

A small world starring dot, populated by many dots, each able to decide and reason on its own, with inference handled by local or remote models — a world shaped by the news it reads from the outside. This is a first sketch, not the final design: the dot/world interaction model is still being figured out.

At a glance

Type
Multi-agent simulation
Actors
Many dots, each deciding and reasoning on its own
Models
One per dot, configurable independently of every other dot — local or remote
External input
News the world reads from outside itself
Shared state
A world state every dot writes to and every dot reads
Status
First sketch — the design is still taking shape

How it works

  1. Perceive — a dot reads the news coming in from outside, and the shared state of the world as it stands
  2. Reason — it thinks that over with its own model, local or remote
  3. Decide — it picks an action
  4. Act — it carries the action out and writes the result into the shared world state
  5. Next tick — the world moves on and the cycle starts over: what one dot wrote is what the others will perceive

Decisions and constraints

  • Every dot reasons on its own — with its own model, independently of every other dot — there is no single brain running the world
  • Dots never talk to each other directly — they influence one another through the shared world state, and nowhere else
  • The world is not sealed off — news from outside feeds into what the dots perceive, so the simulation is shaped by things that actually happened
  • The interaction model is still open — how exactly dots and world affect each other is being figured out. This is a first sketch, not the final design
